No =error=, =[llm]= or =[prompt]= lines — the bot ran cleanly for 205 s and

prose: there was no answer text for the harness to fall back on.

* Root Causes

** RC1 — the packaged library is missing =systems/wh40k/AGENTS.md= (this repo's bug)

=peteches/packages/rules-lawyer.scm= installs only the root =AGENTS.md= plus
=find-files "systems" "\\.txt$"+. Verified on =agents=:

#+begin_example
find $PKG -name AGENTS.md → …/rules-lawyer-0.2.0/AGENTS.md   # the root one only
#+end_example

But =harness.mjs= DISCORD_MODE makes step 2 of the workflow *"read_file that
system's AGENTS.md and follow its rules-query instructions"*. That file is not
in the store, so the bot's *first* tool call returned =Error: not found= — and
the model reads that as "my homework failed". Forced-answer probes produced
this verbatim:

#+begin_quote
I can't give a sourced ruling for "hidden" from this library as currently
exposed. - I tried to read the Warhammer 40,000 system instructions at
=systems/wh40k/AGENTS.md=, but the tool returned *not found*.
#+end_quote

Aggravating detail: the same install phase copies
=systems/wh40k/armies/_reference/import-test/node_modules/playwright*/ThirdPartyNotices.txt=
(2 files) into the library, which pollutes =grep= results across the whole
library. =tools.mjs= skips =node_modules= in =list_dir= only, not in =grep=.

** RC2 — the harness never forces termination

=harness.mjs=: =MAX_TOOL_ITERATIONS = 16=, =tool_choice= hard-wired ="auto"=,
no wrap-up nudge, and on exhaustion it returns =lastText= (empty here) + the
warning. The answer was already in hand at *iteration 2*: =grep [Hh]idden= hit
=core_rules_11th_edition.txt:2325  HIDDEN 13.09= and the following read covered
lines 2280–2399. The remaining 14 turns went into target-selection / terrain /
faction-pack digressions, and =rules/core/universal_rules_updates.txt= — the
file =systems/wh40k/AGENTS.md= declares takes precedence — was only read on
iteration 15.

=tool_choice= is still honoured, whether tools-off leaks =<tool_call>= markup
into =content=, and whether thinking is charged against =max_tokens=.
